# Examples

The following examples cover commonly performed tasks with VARTOOLS. All files referenced
(e.g., `EXAMPLES/1`, `EXAMPLES/2`, etc.) are included in the VARTOOLS distribution and
unpack into the `EXAMPLES/` subdirectory of the installation directory. Commands shown
after the `$` prompt are typed at the shell.

## Overview

| Example | Description |
|---------|-------------|
| [Example 1](example1.md) | Fitting a quadratic polynomial in JD to a list of light curves |
| [Example 2](example2.md) | Performing a Lomb-Scargle period search and fitting a harmonic series |
| [Example 3](example3.md) | Injecting a Mandel & Agol transit signal into a light curve |
| [Example 4](example4.md) | De-trending a light curve with TFA and running BLS on the result |
| [Example 5](example5.md) | Injecting an RR Lyrae signal into a light curve and recovering it |
| [Example 6](example6.md) | Running a battery of variability algorithms on many light curves in parallel |
| [Example 7](example7.md) | Processing a Kepler FITS light curve |
